WHAT'S NEW IN V6.2.2
=====================
- fixed Skill Macro loadouts (and other settings) sometimes disappearing after opening or updating the app; settings are now saved safely with a backup (settings.json.bak)
- fixed hotbar auto-detect (Library Auto and Skill Macro Auto-tune) failing in small Roblox windows or with a bright floor behind the hotbar
- Skill Combo: the step's own wait box is now the wait before M1 (press → wait → M1), new steps start at 0.3 s

WHAT'S NEW IN V6.2.1
=====================
- Library: new 🪄 Auto button for Gold Clover detection - finds the hotbar and your filled slots by itself
- Skill Macro: "then M1" has its own delay (how long to wait after the key before clicking, default 0.3 s), in Rotation and Skill Combo; Items also wait 0.3 s before M1
- fixed the 'OK detection not set up' message pointing to the old main tab (it's on the OK Popup page)

WHAT'S NEW IN V6.2
===================
- fixed Windows_Launcher.bat closing instantly / not opening for some people (wrong line endings, Python in a folder with spaces, or brackets in the folder name)
- fixed Skill Macro slots always showing 'on cooldown' when the hotbar region is a few pixels off or the icon glows
- Skill Macro: new 🪄 Auto-tune: finds the hotbar by itself (only your filled slots), snapshots it and learns each slot's ready line by casting it once (waits for each move to come off cooldown first)
- Skill Macro: per-slot 'Ready at' setting to adjust a slot by hand
- Skill Macro: Auto-tune works with small / windowed Roblox, shows where it found the slots, and stops instead of overwriting your snapshots when it can't find the hotbar
- Skill Macro: New loadout now starts as a fresh empty save instead of a copy of the current one
- Skill Macro: "Hold click" is now a simple "then M1" tick box (move → delay before → key → M1 → delay after), the Move/Click switch is gone
- Mining: new 'Line-up checks' switch (off = just follow the recorded path and press E, no checks)
- Mining: new 'Prompt area' to set where it looks for the [E] Interact prompt
- Mining: removed the old Test Start Spot button and Tolerance slider; Mining no longer stops when it can't recognise the start spot

WHAT'S NEW IN V6
=================
- NEW Skill Macro: auto uses your skills when they're ready, in the order you pick

- Loadouts: save different skill setups and switch between them

- Library Macro: Test Path button works now (also on F3)
- Mining Macro: routes now use however many ores you record
- cleaner and faster menus, with the same big ON/OFF buttons everywhere
- Library Macro: can hide the chat during the minigame so it isn't clicked as a clover
- Library Macro: train up to 9 moves; it scrolls the wisp's list to find each move by name or picture
- Library Macro: gold clovers are found automatically from your hotbar (no more small boxes per move)

- nicer YouTube, Discord and Donate buttons in the main menu
