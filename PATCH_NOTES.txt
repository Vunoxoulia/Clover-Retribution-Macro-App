WHAT'S NEW IN V5.4
=================
- New OCR Engine: Switched from EasyOCR to RapidOCR (PaddleOCR models). This significantly reduces CPU/RAM usage and improves text detection speed.
- Added Fishing Macro: Full automation for the fishing minigame, including customizable bar and fish color detection.
- Experimental Cross-Platform Support: Added `Linux_Mac_Launcher.sh` for Linux and macOS. (Note: These platforms are currently untested and experimental).
- Launcher Optimization: Fixed an issue where the launcher would repeatedly attempt to install Python even if a valid version was already present.
- Improved Compatibility: Replaced legacy Windows-only input methods with a cross-platform input engine (`pynput`) for better support on Linux and Mac.
- Smarter Screen Capture: Added automatic window detection using `pywinctl`, allowing the macro to focus on the Roblox window even when it's moved or resized.
- Intelligent Execution: Added platform-specific execution providers (CoreML for Mac, CUDA for Linux) for near-instant OCR results.
- Core Stability: Refactored base logic classes to prevent crashes during long sessions and improve input handling reliability.

WHAT'S NEW IN V5.3
=================
- Improved Color Detection: Switched to HSV color space for clover detection. This significantly improves reliability for Bronze and Silver clovers.
- Interactive Launcher: `run.bat` can now AUTOMATICALLY download and launch installers for Python and Microsoft VC++ if they are missing.
- Launcher Stability: Rewrote `run.bat` from scratch for maximum compatibility. No more instant-closing windows!
- Microsoft Store Support: Improved compatibility with Microsoft Store Python by suppressing "PATH" warnings and adding better diagnostic info.
- Robust OCR: Added DLL error handling. If dependencies are missing, a popup will guide you to the fix instead of the macro crashing.
- Auto-Repair: `run.bat` automatically checks and upgrades all Python libraries on launch.
- Expanded Dependencies: Added explicit support for Torch and Torchvision to ensure OCR works out of the box.
- Streamlined Project: Removed `MakeItExe.bat`. To prevent Antivirus false positives and ensure the macro remains lightweight and transparent, we now only support running via `run.bat`.

WHAT'S NEW IN V5.2
=================
- Improved Startup: `run.bat` now automatically checks if Python is installed and provides help if it's missing.
- Advanced OCR Matching: Enhanced detection for moves with Roman Numerals (e.g., Arcane Door I-V). It can now handle split text boxes and common OCR misreadings.
- Visual Testing: The Move OCR Test now moves your mouse to the detected location to verify accuracy.
- Documentation: Added clear guides for Prerequisites and Antivirus False Positives.
- Remote Patch Notes: You can now view these notes directly from the Macro Hub!

BUG FIXES:
- Fixed a bug where 'Arcane Door II' would sometimes match 'III'.
- Fixed OCR test logic to be 100% accurate to the main macro behavior.
- Cleaned up internal dialogue handling code.
- Fixed a crash (OSError 126) when OCR dependencies were missing.
