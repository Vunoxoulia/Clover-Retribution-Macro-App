QUICK START
═════════════════════════════════════════════════════════════════

   1. Unzip the download first (right-click the .zip → Extract All)
   2. Double-click: Windows_Launcher.bat  (don't "Run as administrator")
   3. Wait for Python to be found (it offers to install 3.12 if needed)
   4. Wait for the packages to install (only the first time)
   5. The macro opens!

SYSTEM REQUIREMENTS
═════════════════════════════════════════════════════════════════

Minimum:
  • Windows 10 (64-bit)
  • 4GB RAM
  • Python 3.11 - 3.14 (the launcher finds or installs it)
  • Microsoft Visual C++ Redistributable x64 (the launcher tells you if it's missing)

Recommended:
  • Windows 11
  • 8GB+ RAM
  • Display: 1920x1080 at 100% scaling
  • Roblox in Windowed or Borderless Windowed mode

Mac and Linux are not supported.
