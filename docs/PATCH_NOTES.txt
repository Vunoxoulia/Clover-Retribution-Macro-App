WHAT'S NEW IN V6.3.3
====================
- fixed the Skill Macro sometimes stopping right after an OK click: the OK clicker no longer clicks when another window (like the macro's own) covers the popup, and it never switches focus back to the macro window after clicking
- OK popups now take ONE click: the macro brings that Roblox window to the front first, then clicks once
- new: Keep Roblox in focus (on by default) - if the game loses focus while a macro runs, the macro brings its Roblox window back to the front instead of waiting (works with multiple windows: it remembers the one you started in)
- new: a small bar on top of the game shows what the macro is doing right now (casting a slot, clicking OK, anti screen-shake, meditating, walking...) so you can see where something goes wrong - can be turned off
- Skill Macro: snapshots only take the MIDDLE of each hotbar box, so a new clover on a move that isn't maxed yet doesn't make a ready slot look different (old snapshots are cut the same way automatically - retaking them is still best)
- Skill Macro: Find hotbar and Snapshot all now replace drawn boxes with the automatic ones (they used to stay and overlap)
- Skill Macro: fixed the Find hotbar button showing as 'Find hot'
- Event Notifier: the events list has a search box and pages (8 per page) instead of one long scrolling list; the 'who to ping' button now reads '+ ping' / '2 pings'
- Event Notifier: Test button on each event - if its words are in a chat right now it uses that real line (so reading is tested too), otherwise it posts a test message with the same text and pings; 'Last events' list of what was posted; Tick / Untick shown (e.g. search 'wisp', then Tick shown); Export / Import the event list to share it; quiet hours (no posts or pings, still noted); a warning (in the app and on Discord) when a window's chat can't be read for a few minutes; each event can have its own 'again after' minutes

WHAT'S NEW IN V6.3.2
====================
- fixed the window freezing for seconds when opening or starting a macro: pages are now built the first time you open them (Library opens in a fraction of a second instead of ~6 s), Skill Macro cards fill in without blocking, and the text reader and key hook load in the background when the app opens
- warns you when Roblox runs as administrator (Windows then blocks every key and click the macro sends) and how to fix it
- new: Export / Import setups to share them as one .zip - Skill Macro loadouts (settings + snapshots, added as a new loadout) and the Library setup (moves, dialogue mode, spots, pictures + your own route); no webhook or stats are included
- Library and Mining: the record key is now F9 (was Ctrl+P) and can be changed any time in the Hotkeys tab - every hint, the REC badge and the log show whichever key you set
- Library: if the selected route was never recorded (e.g. made with New), it now uses the built-in route instead of asking you to record one
- Library: after picking a move it must SEE the minigame start (a few checks in a row, so a flash doesn't count) before it can decide the minigame is over; it waits up to 30 s (editable: 'Wait for the minigame' in Wisp dialogue), and if it never starts while the dialogue is still open it picks the move again instead of walking off
- Library: new 'Wait after Clover Training' (default 1.5 s, editable in Wisp dialogue) - it waits that long before reading the move list, so it no longer scrolls past a move that's right at the top
- Library (Manual mode): the tests now work with your spots - Hover spots (F4) hovers your move spots, Full test (F5) walks, presses E, clicks your Clover Training spot and hovers the moves - no pictures needed
- Skill Macro: snapshots now only take the inside of each hotbar box (not the gaps / ground beside it); each slot shows its picture (click it to see it big), the new Snapshots button shows them all with Retake, and Draw box lets you drag your own box for a slot

WHAT'S NEW IN V6.3.1
====================
- Library: tests split up - Test Path (F3) only walks the route, Find moves (F4) only reads the move list that's already open (no walking, nothing clicked), and the new Full test (F5) walks the route, opens the dialogue and finds the moves

WHAT'S NEW IN V6.3
==================
- Library: new Auto setup for 'Moves to train' - reads the hotbar slots of the moves you ticked, opens the wisp's move list (scrolling down) and matches them, saving ONE word only that move has (e.g. 'Cage' for Sovereign Magic: Cage Gates); words every move shares are ignored, so misreads like 'Cagt' / 'Cate' still find 'Cage'. If a move has no unique word it suggests Image mode (which also saves each move's picture)

- Library: Manual dialogue mode now just clicks your spots: Clover Training + up to 3 move spots (each with its own tick and hotbar slot for the gold check) - no names, no reading, no scrolling. Image and Auto still use 'Moves to train' and scroll to reach all 9
- Library: the move list is recognized as soon as a button looks ~50% like one of your moves (hotbar / saved names), or when 2+ buttons hold still - 'Skip', Clover Training and Nevermind never count, so it never scrolls while the text is still typing
- Library: the dialogue is found even when it blends into the macro window or a dark floor
- Library: scrolling the move list glides the mouse there first, so Roblox registers it
- Library: if the wisp's dialogue closes (e.g. Nevermind) after it was found, it stays where it is and double jumps + presses E until the dialogue opens again, instead of walking the route again
- Library: new built-in route 'VunVun's route 2' (locked like the first one)
- Library: pressing Ctrl+P on a built-in route now tells you to click New to create your own route
- Skill Macro: Anti screen-shake has an optional screenshot check - pick a spot that looks different while in ',' and after the presses it checks you're really out, pressing ',' again if not
- changes apply right away: text boxes save almost instantly while typing, and Mining picks up route edits from the next lap without restarting
- Mac and Linux support removed (it couldn't be tested and relied on Windows-only parts) - the macro is Windows 10 / 11 only
- updating from an older version: if the macro doesn't reopen by itself after the update, just open Windows_Launcher.bat again
